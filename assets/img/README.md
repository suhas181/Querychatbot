# Images

## logo.png

Save the college logo here as **`logo.png`** (PNG with a transparent or white
background, square, at least 256×256).

It is used as the crest in the header of every page, in the admin sidebar, and
as the browser tab icon.

Nothing breaks if the file is absent — the pages fall back to the "SEA"
lettermark automatically, so the project still runs on a clean checkout.
